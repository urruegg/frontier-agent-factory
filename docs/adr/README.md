# Architecture decisions

Record factory-wide decisions with stable `ADR-0001` identifiers using the
[ADR template](../templates/adr.md). Allocate an identifier once and never reuse it.

Statuses are proposed, accepted, rejected or superseded. Preserve the context,
alternatives and consequences when a later decision supersedes one.

An accepted factory ADR constrains solutions. A solution-specific decision
belongs with that solution and cannot silently weaken factory requirements.

Link the evidence, approving decision and affected specifications. A generated
draft is not an accepted decision.
